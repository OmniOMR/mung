# Demo for the mung2musicxml module

For usage of the module, see [README](../README.md).

## Assets

To allow users to try out the library themselves, we provide three MuNG transcriptions of varying difficulty together with images. The examples are taken from [MusiCorpus 1.0](https://github.com/OmniOMR/musicorpus).

- `13abc7f9-5e3f-4e85-b753-0dab090728fe_9d4412a1-0cf3-4475-a022-9f37984272fb`
    - Single grand staff with clef changes.
- `81c9f683-28d1-4e73-8e25-e37333408f5a_5b6164cc-5653-494b-b43f-946fbb64d440`
    - Single staff and grand staff. 
- `30d6c780-c8fe-11e7-9c14-005056827e51_36058ae0-f593-11e7-b30f-5ef3fc9ae867`
    - String quartet with clef changes.
